>
> The Branching Component has been migrated to **[mustry-perspective-component-module](https://github.com/Mustry-Solutions/mustry-perspective-component-module)**, which is where it is developed and released from now on. This repository is kept for reference only and is no longer maintained.
>
> The migrated **Branching Diagram** is a superset of the component here — every property carries over (`id`, `name`, `color`, `nextId`, `category`, `fill`, `style`, `icon`, `tooltip`, `tooltipStyle`), and it adds vertical orientation, direction arrows, per-edge labels and styling, loop/back-edge routing, localization, and validation feedback for datasets that won't fully draw.
>
> That module ships thirteen further components alongside it — a date/time range picker, calendar/scheduler, resource timeline, data grid, pan & zoom view, rich text editor, code/JSON editor, colour picker and on-screen keyboard, plus an admin family (schedule, roster, user and holiday management). It targets Ignition 8.3, is free (Apache-2.0), and has signed releases.
>
